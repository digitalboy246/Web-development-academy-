Welcome back! Today we're going to learn about HTML attributes.

What is an HTML attribute?

An attribute gives additional information about an HTML element.

Attributes are normally written inside the opening tag. 

<a href="https://example.com">
    Visit Website
</a>

Let's break it down

  • <a> is the anchor element.
  • href is the attribute.
  • "https://example.com" is the attribute value.
  • The text Visit Website is what the user sees and clicks.
💡 Teacher Tip: Think of an attribute as extra information that you give to an HTML element.

Another Example

The src attribute tells an image element where its image comes from. 

<img src="photo.jpg" alt="My photo">

Here, src tells the browser which image to display.

The alt attribute provides alternative text for the image.

💻 Try to understand this

Look at the code below. Can you identify the attribute? 

<input type="text" placeholder="Enter your name">

There are actually two attributes here: type and placeholder.
